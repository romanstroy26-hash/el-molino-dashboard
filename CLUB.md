# El Molino -- система аналитики

## Текущий этап: клиентский API и PWA

Клиентский экран и панель сотрудника оформлены в общей палитре El Molino:
тёмно-зелёный, тёплый кремовый и терракотовый. Интерфейсы адаптируются к
узким экранам; основные стили находятся в `web/styles.css` и
`web/staff.css`. Внешние изображения и шрифты для их работы не требуются.

В этой папке находятся FastAPI API (`api.py`), клиентская PWA (`web/`),
схема и сервис лояльности (`customer_schema.py`, `customer_service.py`).
В этой сборке клиентский API и исходный дашборд используют одну базу.

Для локального запуска API открой `Club.bat` (либо установи зависимости
из `requirements.txt` и запусти `uvicorn api:app`). Ключи
`AUTH_TOKEN_SECRET`, `ADMIN_API_KEY` и `CASHIER_API_KEY` задаются в `.env`.
Локальная SQLite база создаётся при
первом запуске, если `DATABASE_URL` не задан. Не используй тестовые ключи
из тестов в рабочем окружении.

Если облачный сервер временно недоступен при открытии сохранённой сессии,
клиент видит кнопку «Volver a cargar». Вход при этом сохраняется; он
сбрасывается только при ответе API о недействительном доступе.

### Регистрация и вход

Новый клиент может зарегистрироваться в PWA по имени и телефону. Сервер
отправляет одноразовый код через настроенный SMS-обработчик; аккаунт
создаётся только после проверки кода (`POST /auth/register/request-code`,
`POST /auth/register/verify-code`). Существующий клиент входит через
`POST /auth/request-code` и `POST /auth/verify-code`. Код действует 10 минут,
используется один раз; после пяти ошибок блокируется, новый код можно
запросить через минуту. Ответы на запрос кода не сообщают, зарегистрирован
ли номер. Прямое `POST /customers` доступно только кассе с `X-Cashier-Key`.

LabsMobile подключается автоматически, когда в `.env` указаны
`LABSMOBILE_USERNAME` и `LABSMOBILE_API_TOKEN`. Создай новый API-токен в
кабинете LabsMobile и заполни эти две переменные, затем перезапусти API.
Исходящий запрос идёт к `https://api.labsmobile.com/json/send`; код не
записывается в логи. Для проверки доставки используй собственный мексиканский
номер, вводя его как 10 цифр или с префиксом `+52`. Тарифный SMS может
списать деньги со счёта LabsMobile. Если SMS не настроен, API возвращает
503 на запрос кода. Режим `expose_debug_code=True` предназначен только для
локальных тестов и возвращает код в ответе API.
Для проверки соединения без доставки и списания можно временно установить
`LABSMOBILE_TEST_MODE=1`; перед проверкой реального SMS удалить эту строку.
25 сентября 2026 года подключение проверено на реальном мексиканском номере:
LabsMobile принял запрос, получатель подтвердил получение SMS. API-токен
сохраняется только в локальном `.env`; после его замены доступ к API повторно
проверен запросом баланса без отправки SMS.

Покупка записывается через `POST /customers/{customer_id}/purchases`.
Запрос должен содержать заголовок `X-Cashier-Key` и уникальный
`external_reference` (номер чека). Токен клиента и ключ администратора
не дают права на запись покупки. Источник операции и правило начисления
баллов задаются сервером: `cashier`, 1 балл за целый MXN. Повторная
отправка того же чека возвращает прежнюю покупку без повторного
начисления, только если сумма и товары совпадают. Сервер сверяет сумму чека
с суммой товарных строк и каждый
подытог с количеством и ценой; ошибочный чек не начисляет баллы.
Клиентское приложение может читать баланс и погашать rewards.
В разделе «Tus compras» клиент видит 20 последних чеков: дату, сумму, товары
и реально начисленные за каждый чек баллы. `GET /customers/{customer_id}/purchases`
доступен только владельцу аккаунта; параметр `limit` допускает от 1 до 50.

Пример тела запроса кассы:

```json
{
  "total_amount": "150.00",
  "external_reference": "ticket-123",
  "items": [{"product_name": "Cappuccino", "quantity": 2, "unit_price": "75.00"}]
}
```

Прямое подключение Wansoft к клиентскому API не настроено.

### Панель сотрудника

Открой `/staff.html` на том же сервере. Для кассы введи `CASHIER_API_KEY`,
найди клиента по телефону. Если клиент ещё не зарегистрирован, панель предложит
ввести его имя и телефон, после чего можно сразу записать чек. После поиска
видны пять последних чеков клиента с номером, суммой, товарами и баллами;
маршрут `GET /cashier/customers/{customer_id}/purchases` требует `X-Cashier-Key`.
Согласие на
маркетинг отмечается только по просьбе клиента. В чек можно добавить несколько
товаров; итог рассчитывается по строкам, а баллы начисляются по общей сумме.
Для менеджера введи `ADMIN_API_KEY`: панель показывает аудиторию и
рекомендации, позволяет создать reward и черновик кампании по сегменту.
Раздел «Campañas» показывает все кампании, позволяет активировать черновик
и посмотреть число открытий и кликов.
Код панели не сохраняет ключи в localStorage; они остаются в полях
открытой страницы.
Используй страницу сотрудника только через HTTPS в рабочем окружении.

### Выдача rewards

После погашения клиент видит код в разделе «Tus canjes». Баллы списываются
в момент погашения; статус `redeemed` означает, что награда ожидает выдачи.
Сотрудник вводит код в панели и подтверждает выдачу. Статус становится
`fulfilled`, повторное подтверждение отклоняется, а время выдачи
фиксируется событием `reward_fulfilled`. Для кассы также доступны
`GET /cashier/redemptions/{id}` и `POST /cashier/redemptions/{id}/fulfill`
с заголовком `X-Cashier-Key`.

### Кампании и согласие

Новая кампания создаётся со статусом `draft` и пока не видна клиентам.
Активация переводит её в `active`. В получатели включаются только активные
клиенты с согласием на маркетинг; согласие перепроверяется при активации.
Отозвавший согласие клиент перестаёт видеть кампании в приложении.
Открытие кампании и нажатие «Me interesa» учитываются в аналитике.
Внешняя отправка push, SMS и email пока не подключена: активация делает
кампанию видимой только в клиентской PWA.
